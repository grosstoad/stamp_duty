# Australian Stamp Duty Calculator

A comprehensive calculator for Australian stamp duty and government fees with a React frontend.

## Project Structure

- **calculator/** - Core TypeScript calculator library
- **frontend/** - React+TypeScript frontend with shadcn/ui components

## Features

- Calculate stamp duty for all Australian states/territories
- Support for first home buyer concessions
- Calculate transfer fees and mortgage registration fees
- Interactive UI with detailed breakdown of costs
